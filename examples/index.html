tabloom

Demos

An open-source engine for guitar tablature visualisation and learning. Every page below is a few lines of JavaScript over the same engine.

  • Für Elise Written as ASCII tab, parsed by the engine. Note names on, bars detected from the source.
  • Concerning Hobbits DADGAD, built from six overlapping video shots — the same shape the capture pipeline emits.

Reconstruct your own

npm i -g yt-dlp            # optional, for URLs
npm run capture -- "https://youtube.com/watch?v=..." --tuning dadgad

That writes capture/tab.txt (plain ASCII tab), capture/score.json and capture/report.json. Drop the tab into parseAsciiTab() and you have a playable lesson.
